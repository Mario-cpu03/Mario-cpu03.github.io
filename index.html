01 / Flagship

NAPOLEON+

A service-aware simulator for user association across dynamic LEO non-terrestrial networks.

Engineering question

When satellites move faster than the access decision loop, which satellite should serve each user, and when is a handover actually worth it?

NAPOLEON+ generates a moving LEO access scenario, models ground-to-satellite links, evaluates user association decisions across satellites, and measures the result through system-level and service-specific KPIs.

The simulator supports throughput-oriented eMBB and latency/reliability-oriented URLLC policies, with both ideal and forecast channel-state information and dedicated handover logic.

From channel to evidence

A communication link is only useful when its physical assumptions survive contact with statistics.

The project models a geostationary passive-relay SATCOM link between two terrestrial nodes, including environmental and noise effects across the synthetic communication chain.

Simulation outputs are then analyzed statistically, using linear regression to study how operating conditions relate to effective throughput, bit-error rate, and packet-error rate.

03 / Multi-user access

Non-Orthogonal
CDMA.

A MATLAB study of shared-channel access under ideal and noisy conditions using 2-PAM.

MATLABCDMA2-PAMNoise
View repository ↗
User AUser BShared channel

Shared medium

Orthogonality is convenient. Real systems become interesting when users interfere.

This study explores the theoretical and practical behavior of non-orthogonal code-division multiple access for multiple users sharing the same communication channel.

Using a deliberately simple 2-PAM modulation scheme, the simulation isolates the effects of code interaction and noise so system behavior can be interpreted rather than hidden behind complexity.

Modulation trade space

More bits per symbol can buy efficiency, but they also demand a better channel in return.

The MATLAB application studies wireless transmission under fading while comparing 16-QAM and 64-QAM, motivated by the modulation choices introduced around 3GPP Release 5.

The emphasis is on connecting constellation geometry and fading behavior to the system-level reasoning behind modulation selection.
